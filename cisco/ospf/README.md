# OSPF

Choose the topology for your lab. Both guides include the exact cabling, IPv4 settings, router CLI commands, and ping tests.

- [Two routers and two PCs](2router2pc/README.md)
- [Three routers and three PCs](3router3pc/README.md)

## **Algorithm to write in your lab record**

1. Connect the devices according to the selected topology.
2. Set the PC IPv4 settings and router interface addresses.
3. Check the direct links before configuring OSPF.
4. Configure routing using the commands in the selected guide.
5. Verify the routing tables, ping across LANs, and save the project.

[Cisco OSPF reference](https://www.cisco.com/c/en/us/td/docs/routers/ios-xe/ip-routing/b-ip-routing/m_iro-cfg-0.html)
